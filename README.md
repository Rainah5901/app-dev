## My Favorite Movie: *Five Nights at Freddy's 2* (2025)
 
**Genre:** Supernatural Horror / Mystery
**Director:** Emma Tammi
**Writers:** Scott Cawthon, Seth Cuddeback, Emma Tammi
**Studio:** Universal Pictures / Blumhouse
**Rating:** PG-13 | **Runtime:** 104 min
**Release Date:** December 5, 2025
 
### Synopsis
Isang taon matapos ang nangyari sa Freddy Fazbear's Pizza, bumabalik ang animatronic terror. Mas malaki ang banta ngayon, at may bagong kalaban: ang **Marionette**. Based ito sa video game series ni **Scott Cawthon**.
 
### Why I Like It
- Based sa game series na gustong-gusto ko
- Nakakakaba ang mga animatronics (Springtrap, Balloon Boy, Foxy)
- Si Scott Cawthon mismo, ang game creator, ang sumulat ng script
- Masayang panoorin kasama ang barkada
